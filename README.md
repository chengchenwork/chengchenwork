### 02 · Lending Club 信贷违约预测与特征工程评估

**分析问题：** 复杂工程特征能否改善模型对未来周期贷款违约的预测？

- **数据基础：** 基于 **125,000 条贷款样本**，剔除贷后泄露字段，完成 CPI 通胀调整、缺失值填补与类别变量编码。
- **个人贡献：** 构建金融压力、还款能力、信用历史、宏观经济与时间标准化特征，对比 Logistic Regression、LightGBM 和 NODE。
- **评估方式：** 使用 Expanding-window validation 与 Bootstrap，对比 AUC、F1、Precision 和 Recall；项目评估显示 LightGBM 在该数据上的表现更稳定。

`Python` `Pandas` `scikit-learn` `LightGBM` `特征工程` `模型评估`
